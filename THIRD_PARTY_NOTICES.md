# Third-party references and dependencies

The software references OpenGait, Gait3D Benchmark, Deep Sets, Set Transformer, and Bob. Upstream project links are provided in REFERENCES.md. Their source distributions are not bundled in this repository.

Runtime dependencies are PyTorch, NumPy, SciPy, PyYAML, cryptography, and Pillow. Each dependency retains its own copyright and license terms.

Dataset access and distribution are governed by the respective dataset providers. Dataset files, trained checkpoints, domain keys, and run artifacts are stored locally and excluded from version control.
